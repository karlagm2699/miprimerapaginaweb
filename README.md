# 🔐 Cybersecurity | My First Web Page

An informational web page about **cybersecurity**, created as an introductory exercise in the **Mujer Digital** course (Junior Achievement México) to learn the basics of web development.

🔗 **Live site:** https://voluble-muffin-cbe1d1.netlify.app/

## 📚 Content

The page explains, in simple terms:

- **What is cybersecurity?** Protecting systems, networks, devices and data from digital attacks and unauthorized access.
- **Core pillars:** the CIA Triad (Confidentiality, Integrity and Availability).
- **Types of cybersecurity:** network, endpoint, cloud and information security.
- **Common threats:** malware, ransomware and phishing.
- **Best practices:** password managers, two-factor authentication (2FA), keeping software up to date, and being careful with suspicious links and downloads.
- **Related topics carousel:** digital forensics, ethical hacking, and information and identity security (IAM).
- **Links** to the bibliography and recommended courses.

## 🛠️ Technologies Used

- **HTML5**: page structure (header, sections, lists, images and footer)
- **CSS3**: custom styles in `style.css` (colors, typography, margins, borders and shadows)
- **Bootstrap 5.3**: image carousel component
- **Netlify**: website hosting
